# Philosophy

## Core Principles

### 1. Determinism

Every operation produces the same result given the same inputs.
No hidden state. No surprises. The machine is honest.

### 2. Keyboard-First

The mouse is a distraction. The keyboard is direct connection
between thought and action. Every function has a key binding.

### 3. Constraints as Liberation

16 colors. Fixed grid. Limited effects. These are not limitations—
they are boundaries that force creative solutions.

### 4. The Terminal is Sacred

GUI bloat is spiritual pollution. The terminal is pure text,
pure thought, pure signal. No chrome. No distraction.

---

## Influences

### TempleOS

Terry Davis built an operating system as an offering to God.
16 colors. 640x480. HolyC. The constraints were theological.

We borrow the palette. We honor the austerity.

### Renoise / FastTracker II

The tracker paradigm: vertical time, horizontal voices.
A grid that makes rhythm visible. A cursor that makes
composition tactile.

### Pure Data / Max

The patch cable as universal connector. Audio and control
unified in a single paradigm. The graph as instrument.

### Urbit

Deterministic computing. Event logs. Referential transparency.
The machine as mathematical object, not physical substrate.

---

## The 21e8 Principle

> *"21e8" refers to a mysterious number that appeared in physics*
> *and later became associated with aesthetic significance.*

We use proof-of-work hashing not for cryptocurrency, but for
**aesthetic discovery**. Mining a hash is mining a tuning system.
The universe provides the entropy; we provide the ears.

Each hash contains a microtonal scale waiting to be heard.

---

## On Pathologies

Normal music software protects you from edge cases.
CHURCHKEY exposes them.

A continuously irrational meter is mathematically real.
It can be computed. It cannot be performed.

This gap—between computation and cognition—is where
new music lives.
